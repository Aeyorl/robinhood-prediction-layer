# Deployment

## Local

```bash
pnpm install
pnpm dev:infra                       # docker compose: postgres + redis (optional)
pnpm contracts:local                 # anvil + DeployLocal.s.sol (mocks + example markets)
pnpm db:migrate
pnpm seed                            # loads deployments/local.json into postgres
pnpm dev                             # web (3000) + api (3001) + worker
```

Local demo data is generated by mock contracts and is clearly local/test data — never masquerades as live mainnet data.

## Testnet

1. Point env files at chain `46630` (`CHAIN_ID=46630`, testnet RPCs).
2. There is **no official testnet USDG** — never invent one. Deploy `MockUSDG` for testnet/local until an official address is configured.
3. Deploy the protocol core with `Deploy.s.sol` (`OWNER`, `FEE_RECIPIENT`, `CHAIN_ID`), configure feeds via `OracleRegistry`, create markets via `MarketFactory`.

## Mainnet (gated)

- Triggered only through `.github/workflows/deploy-mainnet.yml`, which requires explicit approval on a protected `mainnet` environment and re-runs the full contract test suite before deploying.
- Before any mainnet deployment, verify against official docs (see links in the repo README):
  - USDG: `0x5fc5360D0400a0Fd4f2af552ADD042D716F1d168`
  - WETH: `0x0Bd7D308f8E1639FAb988df18A8011f41EAcAD73`
  - Uniswap Universal Router (chain 4663): currently documented `0x8876789976decbfcbbbe364623c63652db8c0904`
  - Data Streams verifier: currently documented `0xcE73c8ad08CBDEaCa6078BF0627C8fe0a9a536E7`
- Required reviews before launch: contract audit + remediation, compliance/legal review, multisig/timelock ownership, production RPC and observability, load testing, final brand review (see `08_ROADMAP.md` Phases 8–9).

## Address book

All addresses are config-driven in `packages/chain-config/src/addresses.ts`. After deploying, update `marketFactory`, `oracleRegistry`, `chainlinkPriceResolver`, `feeVault`, and `deploymentBlock` for the relevant chain — the worker's backfill start uses `deploymentBlock`.
